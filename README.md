# SafeDial Website

A static, responsive website concept for SafeDial.

## Pages

- `index .html` - Home
- `about.html` - About SafeDial
- `services.html` - Sample products and services
- `contact.html` - Validated enquiry form that opens an email draft
- `marketing.html` - Audience, campaign, SEO and social-media plan

The sample emergency codes are for demonstration only and do not contact real emergency services. In South Africa, call 112 from a mobile, 10111 for police or 10177 for an ambulance in a real emergency.

Open `index .html` in a browser to view the site. The pages use the shared `site.css` and `site.js` files and the image assets in this folder.

## GitHub

This folder can be published as a static site after it is pushed to a GitHub repository. Configure GitHub Pages to deploy from the repository's main branch and root folder, then add the published URL to the page metadata.
